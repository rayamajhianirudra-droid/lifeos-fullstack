# 💪 LifeOS Health — Full Stack

A full stack health and nutrition web app built with Spring Boot + React + PostgreSQL + AI insights.

## Tech Stack
- **Backend:** Java, Spring Boot, PostgreSQL, REST API
- **Frontend:** React, Axios
- **AI:** Google Gemini API for nutrition insights
- **Tools:** Maven, npm, Git

## Features
- User registration and management
- Food logging with calories, protein, carbs, fat
- AI-powered health insights for logged foods
- Real-time calorie tracking

## Running locally
- Backend: `mvnw spring-boot:run` (port 8080)
- Frontend: `npm start` (port 3000)

## Project Structure
- `/src` — React frontend
- Backend lives in separate IntelliJ project
